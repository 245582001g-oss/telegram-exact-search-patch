## 统一回归

实际编译的 x64 代码在两个加载地址运行；Qt 和 Telegram 对象及 Windows 文件系统由受控替身提供。

- 精确搜索、多词 AND、多语言正反例、菜单、全文黑名单、频道 ID 黑名单、普通与预览消息、后续分页和注入消息通过。
- 关键词涵盖 91 个不同频道、改变填充文字、正文/频道名两种范围、普通用户和群组不受影响、当前结果清理、字面量语义、坏文件保留、容量限制与原子写入失败。
- 128 单元重复前缀对 12,000 单元正文的命中/不命中均通过，关键词使用线性匹配；不会自动遍历服务器搜索页。
- 消息与菜单变化后，提示仍使用已复制的建议文本。跳过不写关键词；弹窗期间触发页面销毁后不再访问该页面。
- Windows PowerShell 5.1 管理器 94 项、安装/恢复 40 项、差分重建 24 项、Python 差分包 14 项通过；不支持的 EXE 在写入前拒绝。

## 原生窗口和启动

真实 Win32 独立窗口及真实隔离文件系统验证：建议预填、自定义中文与 emoji、保存、跳过、切换频道名称范围、读取多条规则、删除所选规则，以及 PowerShell 5.1 管理工具互通均通过。测试只用虚构内容，未登录 Telegram。

使用本次完整 EXE 和官方便携组件，从独立空配置目录启动，欢迎页可见且进程响应；自动更新初始设置为 0。欢迎页选择简体中文后，同一进程保持响应，界面已切换为中文。

原生独立弹窗实测与真实账号菜单验收不同：本次尚未人工核对已登录账号里的右键菜单和联网搜索结果，不能把模拟 ABI 测试表述为这一项已完成。建议词只是所选消息的片段，保存后才成为规则，不代表已训练或验证的自动垃圾识别准确率。

## 打包隐私

发布包按固定白名单从官方便携 ZIP 和本次构建生成，不读取已登录的 Telegram 目录。账户、tdata、聊天、缓存、日志、个人黑名单和本机测试文件均不纳入。关键词只在用户确认后写入自己的 Documents/Telegram/blacklists。
