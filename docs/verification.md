验证日期：2026-09-08。构建与回归在独立工作目录执行。本版已完成静态适配、编译产物回归和工具测试；**尚未完成补丁版真实客户端安装、搜索、右键菜单和重启验证**，不把模拟器测试当作客户端运行证明。

逐项核对 55 个代码、导入表、Qt 元数据和测试定时器地址；6 个 CALL Hook 的原始目标与调用者寄存器关系通过反汇编检查。IAT 按 DLL 与函数名映射，未假定固定平移量。

UI 子模块 `Ui::Text::String` 的字段变化导致对象布局改变，已修正 Entry 标志、History peer、InnerWidget 菜单关联消息、事件流、加载状态和菜单指针。使用 History RTTI 和虚表独立确认 `chatListName` 槽 `+0x48`，并对照上游嵌入对象声明。完整迁移依据见 [ABI 清单](abi-7.2.7.json)。

## 编译产物回归

`tests/test_menu_payload.py` 在 `0x140000000` 与 `0x7ff400000000` 两个模拟加载地址执行实际编译出的 Windows x64 指令。每个地址通过 **16 组菜单/黑名单/性能回归及 7 组搜索回归**，覆盖：

- 消息连续字面筛选、多关键词 AND、名称/别名、无结果分页和限定范围透传。
- Qt QAction、九参数连接、排队回调、槽释放与连接失败路径。
- 屏蔽、撤销、跨聊天同文结果、预览结果、容器所有权和失效行对象访问防护。
- 原子规则存储、迁移目录解析、写入失败、长度快速排除和大规则集索引。
- 300 ms 防抖、非易失寄存器、栈对齐及加载标志保持。

测试对象同步到 7.2.7 布局。菜单 FullMsgId 的中间 peer 字段也随结构后移，避免与新的 history 字段重叠；此错误先被回归检测，再修正后通过。测试前后 EXE 与 payload 哈希一致。

`tests/test_language_examples.py` 在两个地址各通过 **73 个多语言和语法正反例，共 146 次匹配检查**，另检查消息、联系人、本地列表和聊天内搜索的作用范围。覆盖英文、简繁中文、日文、韩文、俄文、阿拉伯文、西班牙文、混合文字、emoji、大小写及 Unicode 组合形式。

## 安装、恢复与持久入口

`tests/test_install_tools.ps1` 在 Windows PowerShell 5.1 运行真实工具脚本，**40 项检查通过**，使用合成文件和模拟进程。覆盖新旧版本备份并存、严格哈希、损坏元数据、进程/更新器/锁冲突、恢复拒绝、启动器修复、未知版本保留及启动时文件竞争。更新器检查保守拒绝所有运行中的 `Updater.exe`，防止安装目录的路径别名漏检。

`tests/test_build_rejection.py` 验证兼容性清单与构建器一致，未知哈希在编译或输出创建前即被拒绝；假输入保持不变。

启动器在最终哈希检查与创建进程期间持有同一文件只读句柄，阻止校验后的写入和替换。测试未执行 Telegram、未注册真实登录项，也未访问真实 tdata 或规则文件。

外置入口可修复已支持原版被覆盖的情况。未知新版不修改也不启动；官方更新器直接重启会绕过入口。详见 [升级持久化研究](update-persistence.md)。

## 尚待验证的客户端行为

本版自动化使用合成 Qt/Telegram 对象、WinAPI 桩与内存文件系统。安装后仍需验证实际账号环境的搜索、消息右键菜单、屏蔽后立即刷新、撤销与重启后的规则读取。公开发布不包含私人界面截图或聊天内容。

没有测量端到端网络提速，不保证 Telegram 服务器召回未返回的内容，也不宣称任意未来版本自动兼容。所有结论仅适用于兼容性清单中的指定 7.2.7 文件。
